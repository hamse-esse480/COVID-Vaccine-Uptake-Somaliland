# Project Summary

## Project Title
COVID-19 Vaccine Uptake in Somaliland

## Project Overview
This project analyzed COVID-19 vaccine uptake and its associated factors among survey participants in Somaliland.

## Dataset
- Total observations: 704
- Total variables: 20
- Outcome variable: COVID-19 vaccine uptake
- Uptake: 259 (36.79%)
- Non-uptake: 445 (63.21%)

## Analytical Methods
The analysis included:
- Data assessment and cleaning
- Exploratory data analysis
- Descriptive analysis
- Bivariate analysis
- Multivariable logistic regression
- Model diagnostics and performance assessment

## Key Findings
Factors significantly associated with COVID-19 vaccine uptake in the adjusted logistic regression model included:
- Older age groups
- Higher educational levels
- Vaccine availability
- Previous COVID-19 testing
- Strong perceived threat of COVID-19

The final model had an AUC of 0.7585 (95% CI: 0.7221–0.7949).

## Final Outputs
- Participant characteristics table
- Bivariate analysis table
- Multivariable logistic regression table
- Forest plot
- Results report in Word format
- Dataset codebook
- Analysis scripts

## Conclusion
The findings indicate that COVID-19 vaccine uptake was associated with demographic, educational, access-related, and perception-related factors among the surveyed participants.

## Limitations
The findings should be interpreted in the context of the available survey data and study design. The observed associations should not be interpreted as causal relationships.
